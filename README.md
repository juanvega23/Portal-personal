# Mi portal personal - Taller de Frontend HTML

## Descripción

Sitio web personal desarrollado como práctica de **Diseño de Sistemas en Internet**. Presenta al estudiante, sus intereses y habilidades, una ilustración y enlaces a sitios de interés.

## Objetivo de la actividad

Identificar la estructura básica de un documento HTML y organizar correctamente los elementos de una página web.

## Requisitos de la guía y cumplimiento

| Requisito | Implementación |
| --- | --- |
| Archivo `index.html` | Página principal del proyecto. |
| Encabezado con el nombre | Título principal con `<h1>`. |
| Presentación personal | Párrafos con `<p>`. |
| Lista de intereses o habilidades | Lista `<ul>` con elementos `<li>`. |
| Imagen | Etiqueta `<img>` con ilustración SVG local. |
| Enlaces a redes o sitios | Enlaces `<a>` a GitHub y MDN. |
| Estructura HTML | Etiquetas `<html>`, `<head>` y `<body>`, y títulos `<h1>`, `<h2>`, `<h3>`. |
| README.md en GitHub | Este archivo documenta el proyecto. |

## Estructura del proyecto

```text
Portal_Personal_HTML/
├── index.html
├── README.md
├── css/
│   └── styles.css
└── assets/
    └── ilustracion-estudiante.svg
```

## Cómo ejecutarlo

1. Descarga o clona el repositorio.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. Navega por las secciones **Sobre mí**, **Habilidades** y **Enlaces**.

No se requieren librerías ni instalaciones adicionales.

## Personalización antes de entregarlo

- Reemplaza **Tu Nombre** en `index.html` por tu nombre y apellido.
- Ajusta el texto de presentación y la lista de intereses para que sean reales.
- Modifica los enlaces si quieres mostrar tus redes o sitios favoritos.
- Vuelve a tomar las capturas para el PDF de evidencia si personalizas la página.

## Publicación en GitHub

1. Crea un repositorio nuevo en GitHub (por ejemplo, `portal-personal-html`).
2. Sube `index.html`, `README.md` y las carpetas `css` y `assets`.
3. Confirma que el README aparece en la página principal del repositorio.
4. Copia su URL real y colócala en la entrega de la tarea. Ejemplo de formato: `https://github.com/TU_USUARIO/portal-personal-html` (esto es **solo un ejemplo**, no un enlace publicado).

Opcionalmente puedes publicar el sitio con **GitHub Pages**, configurando la rama principal y la carpeta raíz en *Settings → Pages*.

## Tecnologías

- HTML5 para estructura y contenido.
- CSS3 para estilos y diseño adaptable a dispositivos.
- SVG local para la ilustración de la sección principal.

## Estado

Proyecto local de demostración. **Se debe crear y subir el repositorio real en una cuenta de GitHub antes de entregar la URL al profesor.**
