
# Portal Personal

## Descripción
Página web personal desarrollada como parte de la asignatura Diseño de Sistemas en Internet, con el propósito de aplicar los conocimientos básicos de HTML y CSS en la creación y organización de un sitio web.

## Objetivo
Implementar la estructura básica de una página web utilizando etiquetas HTML para organizar correctamente su contenido.

## Características
- Presentación personal del estudiante.
- Sección de intereses y habilidades.
- Incorporación de imágenes.
- Enlaces a sitios web de interés.
- Diseño adaptable a diferentes dispositivos.

## Tecnologías utilizadas
- HTML5
- CSS3
- SVG

## Estructura del proyecto
- `index.html`: estructura principal de la página.
- `css/styles.css`: estilos y diseño visual.
- `assets/`: recursos gráficos utilizados.

## Ejecución
Para visualizar el proyecto, descargar los archivos del repositorio y abrir `index.html` en un navegador web.
